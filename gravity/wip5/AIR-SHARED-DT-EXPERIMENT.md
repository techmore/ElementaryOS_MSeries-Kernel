# Shared T8132 device-tree integration experiment

Apply `air-t8132-platform-controllers.patch` (Aurora PR 366 commit `573029f8fdcc`) after the source base described in `AIR-USB-SUPERSPEED-EXPERIMENT.md`, then apply `j773g-shared-t8132-dt-reconcile.patch`. This is an experimental series, not a bootable mini release. The PR adds shared T8132 controllers and OPP references; the J713 activation in the USB experiment needs them. The mini's cpufreq controllers and USB hardware remain disabled pending qualified ownership and board-specific resources. The CPU OPP references added to shared CPU nodes still need review for J773g.

The mini draft already supplied SMC, mailbox, and ATC nodes that overlap the newly shared definitions. The reconciliation uses the shared SMC mailbox and explicitly keeps mini SMC and mailbox enabled as in the earlier draft; it reuses shared USB2-only PHY nodes 0 and 1 and reduces the still-disabled mini PHY 3 description to its USB2 and pipehandler banks. The mini's other preexisting USB node properties merge with the shared nodes and need resource and interrupt review, particularly the differing DART register sizes. No SuperSpeed resources have been qualified or enabled for the mini.

Both J713 and J773g DTS files compile with clang preprocessing and the existing WIP5 `dtc`. Each emits a `unique_unit_address` warning for the shared disabled loader-populated `/soc/mbox@0` and `/soc/spmi@0` placeholders. J773g DTB SHA256: `95729698048660a3fb52bea7d598221bd71dfbaaeb586dd758689aafeb9c1545`; J713 DTB SHA256: `103c50d536287c4dbf6fedcac13b0518a5149f961aae907923f89d075a7c42a8`. DT compilation alone does not validate bindings, handoff, kernel drivers, or hardware.

The limited schema check for ATC PHY, DART, PMGR power-state, mailbox, SMC and DWC3 found that the three mini DWC3 nodes used a two-item compatible list rejected by WIP5's DWC3 binding. `j773g-usb-compatible-fix.patch` changes them to the single `apple,t8132-dwc3` value accepted by both the binding and the driver. The updated mini DTB SHA256 is `6b8125fa86b4a6cb1d53cadfaccdafb45578b7b12d6a34e7a749761909c456b1`; revalidation against those six schema IDs emitted no diagnostics. The existing disabled-placeholder duplicate-address warning remains. This limited check is not a full `dtbs_check` or hardware validation.
