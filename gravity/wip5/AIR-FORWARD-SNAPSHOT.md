# Air-forward combined source snapshot

`air-forward-combined-snapshot-draft.patch` reproduces the current focused-build source from the `j773g-integrated` draft source: Aurora WIP5 commit `2f725546d6ac6afe0bd5abfa1a844971519f0076`, the five WIP5 display patches, local J773g patches 0001–0004 and the rear-USB draft that were used as inputs for the long build. It is a combined source snapshot, not an upstream patch series; do not apply it on top of the separate Air experiment patches. The exact 95 changed file paths are listed in `air-forward-combined-snapshot-files.txt`.

Forward application was checked against that baseline and reverse application against `usb-dt-schema-source`. The snapshot includes the focused-build DART range guard, ATC declaration-order fix, mini DWC3 binding fix and J713 SuperSpeed and radio experiments. It does not include un-applied reject files. In particular, the earlier NVMe and CLPC conflicts are not automatically resolved by this snapshot. It has not completed a kernel build, undergone a full binding check, been synced to GitHub, or been qualified on J773g. The rear USB and CPU-frequency resources remain disabled for the mini pending board qualification. This artifact must not be installed or booted as a release.

The snapshot was also applied to a fresh reflink copy of the baseline. All 95 listed paths matched the focused-build source by SHA-256 and executable bits after replay. This verifies those changed files can be reproduced from the specified local baseline; it does not resolve the remaining driver rejects or establish build or runtime correctness.

The separate focused WIP5 build completed `Image` and the J773g DTB successfully (exit 0). Its Image SHA-256 is `5c43fa970b78fffe268f4e763842eb02db5bb4c0da7e29e851516a4c1e77ddb3`, DTB `6b8125fa86b4a6cb1d53cadfaccdafb45578b7b12d6a34e7a749761909c456b1`, config `75b4c9c92d266cec665a072b369a3df6fdb554c0ee30894bb68eb1e4ac281a40`, and kernel release `7.2.11-elementary-wip5-focused-draft`. This diagnostic J713-oriented configuration disables the GPU integration and did not build modules; its DTB lacks the storage handoff marker. It is not an Omarchy package or qualified boot candidate. The latest-source build is separate.
